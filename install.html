Installation

setupmjr is distributed as a compiled Go CLI binary. The canonical installation paths are the published APT repository, the release installer scripts, Scoop on Windows, or a Go source build.

Ubuntu / Debian

APT repository

Configure the published apt-miguelrodo repository once:

sudo apt-get install -y curl gpg
curl -fsSL https://miguelrodo.github.io/apt-miguelrodo/KEY.gpg \
  | sudo gpg --dearmor -o /usr/share/keyrings/apt-miguelrodo.gpg
echo "deb [signed-by=/usr/share/keyrings/apt-miguelrodo.gpg] https://miguelrodo.github.io/apt-miguelrodo stable main" \
  | sudo tee /etc/apt/sources.list.d/apt-miguelrodo.list >/dev/null
sudo apt-get update

Then install or upgrade normally:

sudo apt-get install -y setupmjr

The Debian package depends on bash and repos, so APT installs those dependencies through the repository as needed.

User-local release installer

For a no-sudo installation, clone the repository and run the release installer:

git clone https://github.com/MiguelRodo/setupmjr.git
cd setupmjr
bash install-local.sh

The script downloads the latest release binary, verifies its checksum when checksums.txt and a SHA-256 tool are available, and installs it into the first writable directory already on PATH. If none is writable, it falls back to ~/.local/bin and prints the required PATH instruction. If repos is not already available, the installed setupmjr binary runs setupmjr install --repos.

To uninstall an installation recorded by the local installer:

bash uninstall-local.sh

macOS

Use the same user-local release installer:

git clone https://github.com/MiguelRodo/setupmjr.git
cd setupmjr
bash install-local.sh

The installer supports both amd64 and arm64 release binaries and falls back to ~/.local/bin when no writable PATH directory is available.

Windows

Scoop

A current Scoop manifest is published in MiguelRodo/scoop-bucket:

scoop bucket add MiguelRodo https://github.com/MiguelRodo/scoop-bucket
scoop install setupmjr

The manifest declares repos as a dependency.

Installer script

Alternatively, clone the repository and run the PowerShell installer:

git clone https://github.com/MiguelRodo/setupmjr.git
cd setupmjr
.\install.ps1

The script downloads the latest release binary into the first writable directory already on Path. If repos is not already available, the installed setupmjr binary runs setupmjr install --repos and the installer fails if that dependency installation fails.

To uninstall the recorded installation:

.\install.ps1 -Uninstall

From source

With Go installed, install directly from the module path:

go install github.com/MiguelRodo/setupmjr/cmd/setupmjr@latest

Or build a local clone:

git clone https://github.com/MiguelRodo/setupmjr.git
cd setupmjr
go build -o setupmjr ./cmd/setupmjr

Managed components

After installing setupmjr, use its top-level install command for the external tools whose installation glue it owns:

setupmjr install --repos
setupmjr install --pj
setupmjr install --gh-skill

Flags may be combined. Installers run in a fixed order and stop at the first error:

setupmjr install --repos --pj --gh-skill
  • --repos installs the latest released MiguelRodo/repos binary into ~/.local/bin. Run repos directly afterwards.
  • --pj installs or updates pj from MiguelRodo/pj by shallow-cloning the floating v0 tag and running its installer.
  • --gh-skill installs github-projects from MiguelRodo/github-projects-skill for universal agents at user scope, pinned to main.

At least one target flag is required.

Release assets

GitHub Releases publish binaries for Linux, macOS and Windows on amd64 and arm64. Release archives are .tar.gz on Linux/macOS and .zip on Windows. Bare binaries used by the installer scripts are also published as:

setupmjr_linux_<arch>
setupmjr_darwin_<arch>
setupmjr_windows_<arch>.exe

Verify installation

setupmjr --version
setupmjr --help
