hpc

The hpc subcommand configures Linux HPC environments.

Commands

hpc
hpc scratch
hpc apptainer
hpc slurm
hpc git
hpc r [--not-radian] [--not-lintr] [--switch-r]

Install setupmjr using a supported Linux method from Installation, then verify it with setupmjr --version.

Master setup

setupmjr hpc

The master command is Linux-only and stops on the first failed step. It runs:

  1. Bash rc.d, executable-path and login/profile setup.
  2. Zsh rc.d, executable-path and login/profile setup.
  3. Git identity and GitHub authentication.
  4. HPC scratch configuration.
  5. Apptainer helpers.
  6. SLURM helpers.
  7. Normal setupmjr r defaults.

The focused subcommands below run the same components independently.

Git

setupmjr hpc git

This is the normal setupmjr git setup. It prefers a persistent GitHub CLI login and otherwise uses setupmjr’s protected-token credential helper. See Git for authentication, migration and Dev Container behaviour.

Scratch space

setupmjr hpc scratch

This installs ~/.bashrc.d/hpc-scratch.sh, which points large caches and artefacts at /scratch/$USER when available, including Apptainer/Singularity storage and R library/renv caches.

The master setup wires Bash rc.d first. When running hpc scratch independently, run setupmjr shell bash rc.d first if Bash is not already sourcing ~/.bashrc.d.

Apptainer

setupmjr hpc apptainer

This installs the embedded apptainer-* helper scripts into ~/.local/bin, excluding apptainer-vscode.

SLURM

setupmjr hpc slurm

This installs SLURM helpers into ~/.local/bin, including:

  • slurm-sbatch for job submission and submission records;
  • slurm-sintx for interactive sessions;
  • slurm-squeue for listing the current user’s jobs.

R

setupmjr hpc r

This delegates to the normal R setup and accepts the same flags:

setupmjr hpc r --not-lintr
setupmjr hpc r --switch-r

See R setup for the flag behaviour.
